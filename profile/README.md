# Open-source projects

- [Revit DevLoader](https://github.com/sharafutdinovdi/revit-devloader) installs and updates Revit add-ins from release feeds. [Docs](https://sharafutdinovdi.github.io/revit-devloader/) · [Latest release](https://github.com/sharafutdinovdi/revit-devloader/releases/latest).
- [Revit Model MCP](https://github.com/sharafutdinovdi/revit-model-mcp) exposes Revit model data and controlled model actions through MCP. [Docs](https://sharafutdinovdi.github.io/revit-model-mcp/) · [Latest release](https://github.com/sharafutdinovdi/revit-model-mcp/releases/latest).

The [public roadmap](https://github.com/users/sharafutdinovdi/projects/3) tracks planned work.

## Contribute

Report bugs and propose features through the issue forms in [Revit DevLoader](https://github.com/sharafutdinovdi/revit-devloader/issues/new/choose) or [Revit Model MCP](https://github.com/sharafutdinovdi/revit-model-mcp/issues/new/choose).
Start with an issue labeled [good first issue](https://github.com/search?q=owner%3Asharafutdinovdi+is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22&type=issues) and follow the repository's contribution guide.
