# Security policy

## Report a vulnerability

Use the affected repository's **Security > Advisories > Report a vulnerability** form to report a vulnerability privately.
If private reporting is unavailable, email [sharafutdinov.di.dev@outlook.com](mailto:sharafutdinov.di.dev@outlook.com).

Include:

- The affected repository, version or commit, and environment.
- Steps to reproduce or a minimal proof of concept.
- The expected security boundary and observed impact.
- Relevant logs with credentials and confidential data removed.
- Any known workaround or suggested fix.

Do not open a public issue or disclose details before coordinating with the maintainer.
The maintainer coordinates investigation, remediation and disclosure with the reporter.
A repository's own security policy defines its project-specific boundaries and takes precedence over this fallback.
