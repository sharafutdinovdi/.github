# Support

## Questions

Ask installation, usage and design questions in the affected repository's **Discussions** tab.
Current project discussions are available for [Revit DevLoader](https://github.com/sharafutdinovdi/revit-devloader/discussions) and [Revit Model MCP](https://github.com/sharafutdinovdi/revit-model-mcp/discussions).
If Discussions is unavailable, use the support contact listed in that repository's README.

## Bugs and feature requests

Use **Issues > New issue** in the affected repository and select the relevant form.
Search existing issues before opening a report.
Include the version or commit, operating system, Revit year if applicable, installation method, reproduction steps, expected and actual behavior, and a relevant log excerpt.
Attach a screenshot or recording for a visible problem.
Remove credentials and confidential data from logs and attachments.
Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
